# オプトラボ ― 照度・結像・ビーム・ファイバ・膜を設計する

第7部『[光学](../第7部_光学.html)』のラボ。
**原始部品 ＝ 光線と、その会計（面積×立体角）**。
lx・F値・焦点距離・ビーム半径・屈折率を数値で決めると、
センサ照度・エアリー径・集光スポット・残留反射がその場で出る。
課題はそれを仕様に収める設計問題（4章15問）。ブラウザだけで動く（依存ゼロ・通信ゼロ・乱数ゼロ）。

```
被写体 lx ──→ 輝度 L=ρE/π ──→ センサ照度 ρET/(4N²) ──→ 光子束（第4部の 190/px/s/lx の出どころ）
レーザー w ──→ 集光 w₀=M²λf/(πw) ──→ スポットと NA=w/f ──→ ファイバの窓（両側から閉じる）
```

## 起動

`起動.vbs` をダブルクリック（`index.html` を直接開いてもよい）。
`?fresh=1` で最初から、`?quest=lux` で課題を選んだ状態で開く。

## 画面

- **左** ― 光学系の18個の数値と、そこから出る数字。
- **真ん中** ― 2枚の図。**F値を掃く**（照度は 1/N²、エアリー径は N ― 明るさと解像の綱引き）、**ビーム半径を掃く**（スポットは細く、NA は開く ― ファイバの窓が両側から閉じる）。どちらも採点と同じ `opto.evaluate` から描く。
- **右** ― 課題。採点は設計から出た数字だけを見る。

## 課題 ― 4章15問

| # | id | 名前 | 何を踏むか |
|---|---|---|---|
| | | **第1章　明るさの会計** | |
| 1 | `lux` | カメラ方程式でセンサを照らす | ρET/(4N²)。第4部の 0.52% の出どころ |
| 2 | `inv` | 逆二乗で照らす | E = I/r² |
| 3 | `lockin` | ロックインで床から引き上げる | SNR改善 = √(B_in/B_lock) |
| | | **第2章　結像と限界** | |
| 4 | `lens` | 等倍で結ぶ | 1/a+1/b=1/f、2f-2f |
| 5 | `airy` | 絞りすぎない | 2.44λN ≤ 画素 |
| 6 | `res` | 0.5 µm を見分ける | 0.61λ/NA |
| | | **第3章　ビームと膜と計測** | |
| 7 | `gauss` | レーザーを 20 µm に絞る | w₀ = M²λf/(πw)。太いほど絞れる |
| 8 | `fiber` | ファイバに入れる | スポット≤コア かつ NA≤NA。窓は 3.4〜7mm |
| 9 | `ar` | λ/4 で反射を殺す | R=((n₁n₃−n₂²)/(n₁n₃+n₂²))²、理想 n=√(n₁n₃) |
| 10 | `etd` | LED をファイバに入れる | エテンデュ比 (コア×NA/光源×NA)² が結合の上限 |
| 11 | `cos4` | 隅を暗くしすぎない | cos⁴(atan(像高/f)) ― 広角ほど隅が暗い |
| 12 | `mode` | モードを合わせる | η = (2w₁w₂/(w₁²+w₂²))² ― w₁=w₂ でだけ 100% |
| | | **第4章　偏光・分光・遠くへ** | |
| 13 | `brew` | ブルースター角で p を通す | tanθ_B = n。ガラスで 56.3°、p の反射 ≤ 0.1% の窓は約 53.1〜59.1° |
| 14 | `grat` | 格子の本数を選ぶ | 逆線分散 d/f。範囲 ≤ 12.8 mm と分解能 ≤ 2.5 nm で窓は 400〜426 本/mm |
| 15 | `link` | 80 km を 10 Gb/s で送る | 受信 = 送信 − 0.2×80 − 1 ≥ −18 dBm、広がり D·L·Δλ ≤ 50 ps → Δλ ≤ 0.037 nm |

条件を固定する課題は、**固定した欄を動かすと数字が届いていても落ちる**
（被写体を明るくする・距離を詰める・焦点距離を替える、の類は反則として採点される）。
ファイバと AR はトレードオフの**両側**（細すぎ/太すぎ・低すぎ/高すぎ）が落ちる。

## 数字はどこから来たか

| 量 | 式 | 出どころ |
|---|---|---|
| 1 lx | 1/683 W/m²（555nm 単色として） | 視感効果度の定義 |
| 輝度 | L = ρE/π（ランベルト面） | 測光の教科書 |
| センサ照度 | ρ·E·T/(4N²) | カメラ方程式。第4部「数字の根拠」と同一 |
| 逆二乗 | E = I/r² | 立体角の定義 |
| エアリー径 | 2.44λN | 第4部「解像の限界」と同一 |
| 分解能 | 0.61λ/NA | レイリー基準 |
| 集光ウェスト | w₀ = M²λf/(πw) | ガウスビーム光学 |
| ビーム NA | w/f | 集光円錐の半角 |
| フレネル反射 | ((n₂−n₁)/(n₂+n₁))² | 垂直入射 |
| λ/4 残留反射 | ((n₁n₃−n₂²)/(n₁n₃+n₂²))² | 薄膜光学。SemiLab「反射を殺す」の屈折率側 |
| ロックイン | √(B_in/B_lock) | 白色雑音の帯域則 |
| エテンデュ | G = (πD²/4)·(π·NA²)。結合上限 = min(1, G_受/G_源) | 面積×投影立体角の不変量（輝度保存） |
| cos⁴則 | 周辺照度 = 中心 × cos⁴θ、tanθ = 像高/f | 距離1回・斜め2回・楕円瞳1回の cos |
| モード結合 | η = (2w₁w₂/(w₁²+w₂²))²（同軸・垂直・ガウス同士） | 重なり積分の閉形式 |
| 斜めの反射 | r_s = (cosθᵢ − n cosθₜ)/(cosθᵢ + n cosθₜ)、r_p = (n cosθᵢ − cosθₜ)/(n cosθᵢ + cosθₜ) | フレネルの式（空気 → n）。p は tanθ_B = n でゼロ |
| 格子の分光器 | dλ/dx = d/(m·f)（m = 1、cosβ ≈ 1）、分解能 ≈ dλ/dx × max(スリット, 2 画素) | 格子方程式の微分。第7部 11・第10部 08 |
| 回線 | 受信 = 送信 − α·L − 接続、広がり = D·L·Δλ | dB の足し算と波長分散。第7部 12 |

乱数は使わない ― 同じ設計は必ず同じ数字になり、採点も毎回同じ。

## モデルの外（正直な線引き）

- **収差・ケラレ・多層膜は入れていない。** 斜入射は空気 → 基板の単一界面のフレネル反射だけ（`brew`）。
  格子は 1 次・cosβ ≈ 1 の近似（端で数 % ずれる）で、次数の重なり・迷光・収差はモデル外。
  回線は損失と一次の波長分散だけ ― 偏波モード分散・非線形・受信器の雑音の詳細はモデル外。
  モード結合は同軸・垂直入射のガウス重なりの閉形式 ― 軸ずれ・角度ずれ・非ガウスのモード形はモデル外。
- 測光は 555nm 単色換算。白色光源の lm/W は分光分布に依る。
- 逆二乗は点光源近似（距離が光源径の5倍より遠いあたりから）。

## 検査

```
node tests/all.js
node tests/run.js     式が教科書どおりであること（683・カメラ方程式・2f・回折・ガウス・フレネル）
node tests/quest.js   お手本で通る／反則と両側の失敗が落ちる
node tests/ui.js      画面の通し検査（ブラウザ不要。DOM の模型は SemiLab と共用）
```

`tests/run.js` は **第4部の「数字の根拠」との突き合わせ**（0.52%・光子束 2.1×10⁴/µm²/s @1000lx）を含む ―
2つの部が同じ数字を別の道から出すことの検算。
