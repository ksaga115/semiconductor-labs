# プロセスラボ

**使えるのは工程だけ。** 成膜・露光・エッチング・イオン注入・熱処理を並べてレシピを作ると、
ウェーハの断面が1工程ずつ育っていく。LOCOS もウェルも浅い接合も、部品としては存在しない ―
工程を並べた結果として出てくる。

ブラウザだけで動く。依存ゼロ・通信ゼロ。
[SemiLab](../SemiLab/)（半導体ラボ）の**ひとつ手前の階**で、作った縦の1本はそのまま SemiLab に渡せる。
第4章の課題は SemiLab の物理（ポアソン方程式・光）で採点する。

```
   工程        →    不純物の分布    →    素子（Vth・量子効率）
  ＝ここ（ProcessLab）              ＝SemiLab
```

参考書の[半導体製造プロセス体系マップ](../半導体製造プロセス体系マップ.html)が「どう作るか」を説明する側、
こちらは**自分で作って、何ができたかを計算で確かめる**側。参考書の各工程の末尾に、対応する課題へ飛ぶ箱がある。
全体の位置は [学びの地図](../index.html)（第1部）。

## 起動

`プロセスラボ.vbs` をダブルクリック。**SemiLab と同じフォルダ（`Labs\半導体\`）に兄弟として置くこと** ―
SemiLab の物理（`../SemiLab/src/*.js`）を読み込んでいる。

- `?fresh=1` … 保存を無視して空のレシピから
- `?demo=locos` … その課題のお手本のレシピを置く（`&sel=` で見る工程、`&depth=` で見る深さ）

検査: `node tests/all.js`

## 最初の5分

1. 起動すると「リンを打って、窒素で焼く」だけのレシピが入っている。断面は青（n 型）に染まり、
   白い点が**接合**（列ごとに解いた位置）。
2. 左のレシピで「1」（注入）をクリック。**焼く前**のウェーハに戻る。濃い層が表面近くに薄く乗っている。
   「2」をクリックすると、熱で広がって深くなる。
3. 「2」を選んだまま温度を 1100 に変えて Enter。接合がぐっと深くなる。下の分布の図で、白い線
   （正味の濃度）が基板の点線と交わるところが接合。
4. 「熱処理」を足して雰囲気を「ウェット酸化」に。表面に黄色い酸化膜が育ち、シリコンの表面が下がる。
5. 右の課題から「ゲート酸化膜を育てる」を選んで、自分で作って採点する。

## 操作

| | |
|---|---|
| 工程を足す | 選んでいる工程の**すぐ後ろ**に入る |
| 工程をクリック | その工程の**直後**のウェーハが真ん中に出る。編集欄が開く |
| ▲ ▼ | 順番を入れ替える |
| 数値欄 | Enter か欄を離れたときに反映。読めない値は赤くなり、何も変わらない |
| マスク | 帯をクリック・ドラッグで塗る（明るい所が開口）。左半分・右半分などのボタンもある |
| 断面をクリック | 縦に切る位置が変わる（下の分布の図がそこになる） |
| SemiLab で開く | 縦の1本を SemiLab の新しいタブで開く。「ダイオード」は膜を外して表面に電極、「MOS」はシリコンの上の酸化膜をゲートにする |

数値は `1e15`・`1×10^15`・`10¹⁵` のどれでも読む。

## どこまでが厳密で、どこからがモデルか

### 2次元にしたところ、しなかったところ

- **膜の積み方（成膜・エッチ・酸化）は列ごとの1次元。** 側壁に膜が付く、エッチが横に回り込む、
  LOCOS の端の鳥のくちばし（bird's beak）は出ない。やるなら形状の追跡（レベルセット）になる
- **不純物の拡散は本当に2次元で解く。** マスクの端で接合が横に回り込むのは出る（ウェルの課題で効く）
- 注入の横方向の広がり（横の飛程のばらつき ≒ 0.75ΔRp）も入れてある

### 使っているモデル

| | モデル | 確かめたこと（tests/run.js） |
|---|---|---|
| 酸化 | Deal-Grove（<100>）。ドライの薄い領域は `(1+g·e^(−x/7nm))` を掛ける | ウェットは Deal-Grove と一致、ドライは 1000℃以上で 1% 以内、900℃ で 14% 低い |
| 注入 | ガウス分布。Rp・ΔRp は Gibbons の表を丸めて対数内挿 | ピークの深さ＝Rp、ピークの濃さ＝Q/(√2π ΔRp) |
| 膜越しの注入 | 膜をシリコン換算の厚みにする（レジスト 0.55、窒化膜 1.3 …） | 1µm のレジストは B 100keV をほぼ止め、300nm は B 200keV に抜かれる |
| 拡散 | 真性拡散 D = D0 exp(−Ea/kT)（Sze） | 量が保存される、σ² = ΔRp² + 2Dt、接合深さが解析解（鏡像込み）と 2% 以内 |
| 酸化で食われる | シリコン 0.44 × 酸化膜厚。B は酸化膜に取られて消え、P・As は界面に押し寄せる | |
| シート抵抗 | SemiLab の移動度（Caughey-Thomas）。B 3e20・P 5e20・As 3e20 で頭打ち | 一様な層で 1/(qµNt) と一致 |

### 入れていないもの

チャネリング / 注入の損傷による増速拡散（TED）/ 濃度に依る拡散（高濃度の As・P は実物では速い）/
酸化増速拡散（OED）/ 窒化膜の下の鳥のくちばし / 側壁への成膜 / ポリシリコン・金属の酸化 /
ゲート電極の材料（SemiLab に渡すときは n⁺ ポリのゲートとして扱う）。

実物の浅い接合は TED のせいでここの値より深くなる。**ここの接合深さは「理想の下限」**と思って読むこと。

### SemiLab に渡すとき

なだらかな分布を、**濃度が同じくらいのところ（対数で 0.12 以内）で区切って**薄い層にする。
符号が変わったら必ず区切るので、接合は層の境目に来る。60 層を超えたら許容を広げてやり直す。
計算した 8µm の下に基板を 6µm 足す（ダイオードの裏の電極を遠ざけるため）。

**SemiLab のダイオードの式（I-V・暗電流）は、接合の隣の層の濃度で Vbi や飽和電流を出す。**
なだらかな接合では隣の層はほとんど打ち消し合って薄いので、この式の値はずれる。
ポアソン方程式を解いた値（空乏層・電界・量子効率・Vth）は正しい。だから第4章の採点は後者だけで行う。

## 繰り返し踏んだ落とし穴

### 1. 後退オイラーは裾を太らせる ― 接合が 16% 深く出た

陰解法（後退オイラー）の1刻みは、分布の裾を**ガウスではなく指数関数**で広げる。
接合はピークの5桁下、まさに裾にあるので、刻み 6 で接合深さが 16% 深く出た。
誤差は刻み数に反比例でしか減らず、1% にするのに 400 刻み要る。

→ **クランク・ニコルソン**（2次精度）にした。20 刻みで 0.6%。ただし CN は注入直後の尖った分布で
振動するので、**最初の1刻みだけ後退オイラーを4つに割って均す**（Rannacher の始動）。

ウェルが右半分まで染まって見えたのも、半分はこの太った裾のせいだった。

### 2. 計算する深さが 4µm では足りなかった

ウェル（1150℃ で数時間）を打つと、リンが底まで届き、底は「流れない」境界なので溜まって、
いつまでも基板の濃度まで下がらず**接合が見つからなかった**。→ 8µm にした（2µm から先は 100nm 刻み）。

### 3. 薄い酸化の係数を見当で置いた

`g = 4.0` と見当で置いたら、1000℃ 1時間のドライ酸化が教科書の半分（25nm）しか出なかった。
→ 「x_i = 25nm の Deal-Grove と一致する」ように二分法で合わせて `g = 34.38`。

### 4. ウェルは横にも広がる

1150℃ で 5 時間焼くと、ウェルは深さ 4.2µm になるが、横にもマスクの端から 3.4µm 進んで、
右半分（端から 2.5µm）まで n 型になった。お手本は 90 分（深さ 2.5µm・横 2.0µm）。課題のヒントにも書いてある。

（最初は「深さ 5µm」と書いていた。後退オイラーで太った裾の値で、クランク・ニコルソンに替えたあと
精査で数え直して直した。**解き方を替えたら、説明に書いた数字も数え直すこと。**）

### 5. 検査の DOM 模型はイベントを親へ伝えない

レシピの ▲▼ はブラウザでは行（`.shead`）の中のボタンで、クリックは行まで上がってくる。
模型ではボタンに撃っても行の処理が動かず「動かない」と誤判定した。→ 行に「▼ から来た」として撃つ。

### そのほか（SemiLab から持ち込んだ約束）

- 編集欄は数値欄と選択肢だけ。摘み（range）を使わないので「動かしている最中に一覧を作り直して
  摘みが消える」は起きない。マスクの塗り絵は、塗っている間は絵だけを描き、指を離したときに反映する
- 読めない値は赤くして何も変えない（勝手に 0 にしない）
- **見た目の崩れは Node の検査では落ちない。** 1280px と 1024px で headless Chrome のスクリーンショットを撮る
- `*.vbs` は UTF-16LE(BOM)。起動行の `""""` が潰れていないかも `tests/ui.js` が見ている

## 検査

```
node tests/all.js
node tests/run.js      物理（教科書の式と突き合わせる）
node tests/quest.js    課題（お手本が通る／通ってはいけないものが通らない）
node tests/ui.js       画面（本物の index.html と ui.js を Node で動かす）
```

`tests/quest.js` の「落ちるべきもの」は、SemiLab で2度間違えた教訓どおり**成り立つことだけ**を課す:
何もしないウェーハでは通らない／全体として他のお手本で通る割合が低い／酸化の課題は酸化しないレシピでは
通らない／マスクの課題はマスクを使わないレシピでは通らない／盾の課題は既定のレジストでは通らない。
