# 半導体ラボ

**シリコンの一片に不純物を塗ることしかできない。** そこから pn 接合・ダイオード・
フォトダイオード・MOS・MOSFET まで、全部自分で積み上げる。

ブラウザだけで動く。依存ゼロ・通信ゼロ・インストール不要。
[NandLab](../NandLab/)（NAND だけから論理回路）と [CoinLab](../../ほか/CoinLab/)（コイン1枚から確率）の3本目で、
**NandLab のひとつ下の階**にあたる。第5章で作る MOSFET が、そのまま NandLab の
原始部品 NAND の中身になる。

```
   不純物   →   pn接合   →   MOSFET   →   NAND   →   ALU
  ＝ここ（SemiLab）                    ＝NandLab
```

[学びの地図](../index.html)では**第2部「なぜ動くか ― 素子の物理」の実践**にあたる。第2部の参考書
（半導体デバイスの基礎）はまだ書いていないので、それまでは この README の「仕組み」「どこまでが厳密で、
どこからがモデルか」と、各課題のヒントが説明の役を担う。

## 起動

`半導体ラボ.vbs` をダブルクリック（既定のブラウザで `index.html` が開く）。
`index.html` を直接開いてもよい。

- `?fresh=1` … 保存を無視して空から始める
- `?quest=vth` … 最初からその課題を選んでおく
- `?demo=photo` … その課題のお手本を置いて開く（`&sel=` `&bias=-5,0` `&light=1` など。画面の確認用）
- `?stack=<層の並びの JSON>&from=<名前>` … [プロセスラボ](../ProcessLab/)の「SemiLab で開く」がこれで来る。
  今の作業台は黙って捨てず、「残した素子」に「前の作業台（日時）」として退避してから置き換える

検査は Node だけで走る（ブラウザ不要）:

```
node tests/all.js
```

## 最初の5分

1. 起動すると **n 型の一片が1枚**置いてある。左の「層」でその行をクリックし、
   **Nd の摘みを動かす**。キャリア濃度の段（対数）で電子の線が上下する。
   1e13 から 1e21 まで、8桁ぶん動く。
2. 「シリコン」を押して**2枚目**を足す。足した層の **Na** を上げ、**Nd** を「入れない」にする。
3. その瞬間、断面図に**空乏層**が現れる。これは描いたのではなく、
   ポアソン方程式を解いた結果そこが空乏している。
   バンド図も曲がる。下のバーに `Vbi` が出る。
4. 上の「左」の電圧を **−2V** にする。空乏層が伸びる。「平衡へ」で戻る。
5. 右の課題から「はじめての接合」を選び、**採点する**。

ここまでで、このアプリの全部の操作を使っている。あとは積み上げるだけ。

## 操作

### 左のパネル

| | |
|---|---|
| シリコン | 一片を末尾に足す |
| 酸化膜 | 酸化膜を**先頭に**挟む（左端が自動でゲートになる） |
| 層の行をクリック | 選ぶ／編集欄を開く |
| ▲ ▼ | 層の順を入れ替える |
| 厚み / Nd / Na | 対数の摘み＋数値欄。Nd・Na は摘みを左端まで下げるか、数値欄を空にすると「入れない」（＝0） |
| 複製 / 消す | その層を |
| 残した素子 | 「残す」で名前を付けた構造。クリックで作業台に呼び戻す |

### 上のバー

| | |
|---|---|
| 温度 | 摘みは 200〜450K、数値なら 150〜500K。ni が指数で効くので、少し動かすだけで漏れが桁で変わる |
| 左 / 右 | 両端の電極にかける電圧。摘みは −50〜+10V、**数値なら −200〜+20V** |
| 平衡へ | 両方 0V に戻す |
| 光 | 左から光を当てる（波長・反射防止） |
| 測る | I-V / C-V / 量子効率 / MOSFET の Id-Vd |
| 道のり | どこまで積み上がったか |
| 残す・書き出し・読み込み・作業台を消す | |

### 真ん中（4段）

| 段 | 出るもの |
|---|---|
| 断面 | 層の並び・空乏層・接合・電極・光 |
| バンド図 | Ec / Ev / Ei / EFn / EFp（電位を裏返したもの） |
| キャリア濃度 | n と p を対数で。点線は \|Nd−Na\| |
| 下の段 | 電界 / 電荷 / 光の生成（切り替え） |

**拡大**の摘みは、左端から見る幅を変える。フォトダイオードは 200µm あるのに
面白いのは手前 1µm なので、これがないと何も見えない。

### 数値で打ち込む

摘みの横の欄に打って **Enter**（か欄を離れる）で反映する。読めない値は欄が赤くなり、何も変わらない
（**勝手に 0 にしない** ― 打ち間違いで不純物が消えるのが一番まずい）。範囲の外は端に寄せ、寄せた値が欄に出る。

| 欄 | 書ける形 | 範囲 |
|---|---|---|
| 濃度 Nd / Na | `1e17` `3.6E17` `1×10^17` `10¹⁷` `１ｅ１６`、空か `0` で「入れない」 | 1e10〜1e21 cm⁻³ |
| 厚み | `300`（nm）`300nm` `2.5um` `2.5µm` `0.2mm` | 0.5nm〜1mm |
| 電圧 | `-150` `−5`（全角マイナス可）`12V` | −200〜+20 V |
| 温度 / 波長 / 反射 | 数だけ（単位は付けても読む）。反射は空で「裸」 | 150〜500K / 250〜1200nm / 0〜100% |

### モデルの外に出たら、赤い帯で知らせる

電圧を大きくできるようにしたので、このモデルが扱えないところまで簡単に行ける。
厄介なのは**数値としては解けてしまう**ことで、絵だけ見ると本物らしく見える。だから黙って描き続けない:

| 知らせ | 条件 |
|---|---|
| 降伏 | シリコンの最大電界が降伏の目安（Sze の近似 `4e5/(1−log₁₀(N/1e16)/3)` V/cm、薄い側の濃度 N）を超えた。**このモデルは降伏を出さない**ので、実物なら流れ出す電流が出ない |
| 絶縁破壊 | 酸化膜の電界が 10 MV/cm を超えた |
| 大注入 | 順方向がビルトイン電位に届いた。小注入の準平衡の外 |
| 縮退 | 5×10¹⁹ を超える濃度の層がある。ボルツマン統計の外 |
| 未収束 | 段階的に上げても収束しきらなかった |

MOS の表面は反転層で 1e6 V/cm 近くまで行くのが普通なので、MOS では降伏の判定はしない（酸化膜だけ見る）。

**大きな電圧は 0V から段階的に上げて解く**（1段 5V、前の解を次の初期値にする連続法）。
いきなり −500V を解くと初期値から遠すぎて収束しない（フォトダイオードで実際に踏んだ）。
直接解けたときは余計な計算をしない。何段で上げたかは下のバーに出る。

## 課題 ― 5章 22問

| 章 | 何をやるか |
|---|---|
| 第1章 一片のシリコン | n型 / p型 / 打ち消す / 抵抗率をあわせる |
| 第2章 接合が立つ | はじめての接合 / Vbi を合わせる / 片側接合 / 逆バイアス / pin |
| 第3章 ダイオード | 整流する / J₀ を下げる / 短基底 / 暗電流 |
| 第4章 光を電気にする | 光が見える / 青を拾う / 赤を拾う / 反射を殺す / 広く拾う |
| 第5章 MOS、そして NAND の中身へ | MOSキャパシタ / Vth を合わせる / S値 / NAND の中身へ |

**採点は振る舞いだけを見る。** お手本と層の並びを見比べる採点は一切しない。
「濃度をいくつにしろ」ではなく「電子濃度をこの範囲にしろ」と言うので、
そこへ辿り着く道は何本あってもよい。

「お手本を見る」で出る構造は**正解ではなく一例**。
画面のお手本と `tests/quest.js` は同じ `answer.js` を使っているので、
判定を変えたときにお手本が置き去りにならない。

## 仕組み

```
phys.js    物理定数と材料（ni, Eg, µ, τ, 吸収係数 α, 反射）
  ↓
stack.js   層の並び と、その上に張る格子（非一様・界面で細かく）
  ↓
poisson.js 非線形ポアソン方程式をニュートン法で解く（三重対角・Thomas 法）
  ↓
band.js    電位をエネルギーに裏返してバンド図にする
dev.js     素子として読む（ダイオードの I-V、MOS の Vth、C-V、Id-Vd）
light.js   光の吸収と、少数キャリアの拡散方程式（これも三重対角）
  ↓
quest.js / answer.js   課題と採点、お手本
store.js   保存（localStorage）
  ↓

main.js    起動
```

`ui.js` 以外はブラウザに触らないので、検査は全部 Node で走る。

### 単位系

長さは **cm**、濃度は **cm⁻³**、誘電率は **F/cm**（半導体の現場に合わせた）。
画面に出すときだけ µm / nm に直す。**内部では絶対に混ぜない** ―
ここを混ぜると、空乏層幅が 1e4 倍ずれても気付けない。

### 保存場所

`localStorage` の `SemiLab.v1`。壊れていたら `SemiLab.broken` に退避してから空で始める
（既定値で黙って上書きしない）。

## どこまでが厳密で、どこからがモデルか

**ここを曖昧にしないのが、このアプリで一番大事なところ。**
出ないものを出たように見せるほうが、出ないと言うより害が大きい。

### ポアソン方程式を解いて出しているもの（＝数値解）

- 電位 ψ(x)、電界 E(x)、キャリア分布 n(x) / p(x)、正味電荷 ρ(x)
- 空乏層幅、ビルトイン電位、最大電界
- MOS の表面ポテンシャル、反転電荷、**しきい値電圧**、フラットバンド電圧
- 容量（C-V は dQ/dV を数値微分している。式を当てはめてはいない）
- MOSFET の Id-Vd（チャネル電位ごとに解いて反転電荷を積む。二乗則を仮定していない）

唯一の近似は **準フェルミ電位を与えていること**（下記）。

### 教科書の解析式で出しているもの（＝モデル）

- ダイオードの電流: ショックレー式 ＋ 空乏層の SRH 再結合（n=2 の項）＋ 直列抵抗
- I-V の中で使う空乏層幅（毎点ポアソンを解くと遅いため）。
  ポアソンで解いた値との差が **7% 以内**であることを `tests/run.js` が見ている
- 移動度（Caughey-Thomas）、寿命（濃度依存の SRH）、吸収係数（実測の表を対数内挿）

### 準フェルミ電位の置き方

ドリフト拡散を連立していない。代わりに φn・φp を**与える**:

- **平衡（バイアス 0）** … φn = φp = 0。これは近似ではなく厳密
- **pn 接合にバイアス V** … φn は n 側電極の電位で全域一定、φp は p 側電極の電位で全域一定
- **MOS** … シリコン側は全部ボディ電極の電位
- **MOSFET のチャネル** … 電子だけチャネル電位、正孔はボディ電位

この置き方にすると、n 側の少数キャリアが **p = (ni²/Nd)·exp(V/Vt)** と自動的になる。
ショックレーの境界条件を別途書き足す必要がない ― 置き方から出てくる。

### 出ないもの

大注入 / 降伏（アバランシェ・ツェナー）/ 界面準位 / 量子効果（薄い酸化膜のトンネル、
反転層の量子化）/ 時間の話（高周波 C-V、スイッチング）/ 接合が2つ以上ある構造の
バイアス下（npn などは平衡でだけ意味のある解になる）/ 2次元の効果。

### ni をどう決めたか

教科書は 300K のシリコンについて `Eg=1.12 eV`・`Nc=2.8e19`・`Nv=1.04e19` を並べるが、
`ni = √(Nc·Nv)·exp(−Eg/2kT)` にこの3つを入れると **6.9e9** が出る。
一方、同じ教科書が `ni = 1.0e10` と書いている。**この3つは互いに整合していない。**

このアプリは **ni = 1.0e10（実測側）**を採る。下流の式（Vbi、少数キャリア濃度、
飽和電流）がどれも ni に強く依存していて、手計算で確かめるとき誰もが 1e10 を使うから。
Nc・Nv はバンド図で Ef の位置を描くのにしか使っていない。

## 設計判断とその理由

### 原始部品は「シリコンの一片」ひとつだけ

「pn 接合を置く」という操作は無い。**接合は部品ではなく、濃度の違う一片を
隣に置いた結果として勝手に立つ。** ここがこのアプリの本体で、
NandLab が AND を配らないのと同じ理由。

同じ考えで、電極の種類も自分で決めない:

- 電極がシリコンに触れている → **オーミック電極**
- 電極が酸化膜に触れている → **ゲート**

酸化膜を端に置いた瞬間、その電極はゲートになる。
MOS を「作った」のではなく、酸化膜を挟んだらそうなった、という順番にしてある。

### 作業台は1次元の断面

2次元にすると物理が解けなくなる（か、解くのに何十秒もかかる）。
1次元なら**本当に解ける**ので、絵を描くのではなく計算した結果を見せられる。
MOSFET だけは横方向が要るが、そこは「チャネル電位ごとに1次元を解いて積む」
という教科書どおりの扱いにした。

### 格子は界面で細かく、離れるほど粗く

濃度 1e17 のデバイ長は 13nm、1e19 なら 1.3nm、反転層に至っては 1nm 未満。
一方でシリコン全体は数 µm ある。一様格子では百万点要る。

**刻みの細かさは「その層の濃度」ではなく「界面の両隣の細かいほう」で決める**（後述の落とし穴）。

### 制御体積は左右の半分に割る

界面の点は左右の層で共有される。その点の体積をひとまとめにして片方の濃度を掛けると、
隣の層の体積ぶんまでその濃度で数えてしまう（後述の落とし穴）。

### 色の役割は1つに絞る

赤 = p型 / 青 = n型 / 黄土 = 酸化膜 / 銀 = 電極。この4色を他の意味に使わない。
混ぜると断面図が読めなくなる。

## 繰り返し踏んだ落とし穴

**同じところで3回間違えた。全部「解は正しいが、測り方か格子が間違っていた」。**

### 1. 制御体積が界面をまたいでいた

界面の点の体積を `(hl+hr)/2` とひとまとめにし、片方の層の濃度を掛けた。
p⁺(1e19) と n(1e16) を隣り合わせたとき、**n 層に居るはずの電荷が
層の全ドーパント量を超える**という、あり得ない値が出た。

→ 点ごとに `dxL`/`dxR`・`netL`/`netR`・`matL`/`matR` を別々に持つ（`stack.js`）。

### 2. 格子の刻みを層ごとに独立に決めていた

p⁺(1e19) から染み出した正孔は 1.3nm で減衰するのに、隣の n(1e16) 層の刻みは
自分の濃度から 10nm と決まる。その1点の箱で電荷を2倍以上多く数え、
**空乏層幅が4倍**になった。

→ `edgeStep()` で「界面の両隣の細かいほう」に合わせる。
酸化膜に接するシリコン面はさらに細かく（0.05nm）― 反転層が 1nm 以下にできるため。

### 3. 空乏層幅を「接合の片側の電荷 ÷ 濃度」で測っていた

片側接合では、**p⁺ 側の正孔が接合のすぐ n 側まで染み出している**。
接合上の正孔は約 Na で、Vt/E ≒ 数 nm で減衰する。積分すると 1e12 cm⁻² になり、
ドナーの空乏電荷 3e11 cm⁻² を上回る。ポアソンの第一積分で手計算しても同じ値になった ―
**解ではなく定義の問題**だった。

→ **多数キャリアの欠損**で測る: `Wn = ∫(1 − n/Nd) dx`。
染み出した少数キャリアは入らない。これで全条件で空乏近似と 7% 以内に収まる。

（本当の双極子電荷は `qDep = ε·Emax` として別に持っている。片側接合ではその大半が接合脇の正孔の山で、
**バイアスを変えてもほとんど動かない**。だから C-V が測っているのは qDep ではなく、
空乏層の端で動く電荷 `qMove`（一様な層なら q·N·W）。以前ここに「C-V が測っているのは qDep」と書いていたのは誤りで、
接合の C-V をポアソンから取るようにしたときに容量が1桁小さく出て気付いた。）

### 3'. 空乏層幅の関数が「左が p」と決め打ちしていた

n を左、p を右に置くと空乏層幅が **0** になった。検査の構造がどれも p を左に置いていたので、
ずっと気付かなかった（精査で読み直して見つけた）。→ 接合の左の型を見て、左右それぞれの多数キャリアで測る。
型ごとの幅（wp / wn）と、位置ごとの幅（wL / wR）を分けて返す。絵や光の計算で「どこからどこまで」を出すのは wL / wR。

### 3''. 「1/C² の切片は Vbi − 2kT/q」は、片側が濃い接合では成り立たない

接合の C-V から Vbi を読み戻すと、p+(1e19)/n(1e15) で約 6.7kT/q（0.17V）低く出た。
刻み・当てはめる範囲・厚みを変えても同じだったので、数値の誤差ではない。
両側が同じ濃さ（1e17/1e17）なら差は約 2.5kT/q で、教科書の「2kT/q」に近い。

片側が濃いと、濃い側から染み出した正孔が n 側の最初の約 0.2V ぶんのバンドの曲がりを受け持つ ―
そこはドナーではなく正孔の電荷で曲がっているので、ドナーの空乏から出す 1/C² に見えない。
濃度（傾き）のほうは 1% 以内で読み戻せる。画面の説明と検査は、この差を kT/q の何倍かで出している。

### 4. 準フェルミ電位を接合で「両方いっしょに」切り替えた

接合のすぐ n 側で「φp は p 側の電位、ψ はまだ p 側の低い値」という組み合わせになり、
`p = ni·exp((φp−ψ)/Vt)` が exp(200) まで跳ねて解が壊れた。

→ φn は n 側電極の電位で全域一定、φp は p 側電極の電位で全域一定（教科書どおり）。

### 5. 接合の位置を格子の内挿で出していた

濃度は一片ごとに一定なので**接合は必ず界面の上にある**。
符号が変わった区間を線形に内挿すると、刻みの半分だけずれた位置が返る
（0.5µm のはずが 0.5016µm になった）。→ 界面の点そのものを返す。

### 6. 真性層を挟むと接合を見落とした

p⁺ / i / n⁺ の型の並びは `[-1, 0, +1]`。隣どうしだけを見て「両方 0 でないとき」に
数えると、0 が挟まっているせいで**どこにも変化が無いことになり、pin がただの一片と
判定される**。→ 0 を先に取り除いてから数える（`signFlips`）。

### 7. 真性層の空乏層を電荷で測ろうとした

i 層には残る電荷がそもそも無いので、電荷で測ると幅 0 になる。
→ 電界で測る（`fieldSpan`）。

### 8. 摘みがドラッグできなかった

層の摘みを1目盛り動かすたびに `renderLayers()` で一覧ごと作り直していた。
**つかんでいる摘みそのものが DOM から消えるので、ドラッグが1目盛りで切れる。**
Node の検査は `input` を1回ずつ撃つだけなので通ってしまい、使ってみて初めて分かった。

→ 動かしている間は値の表示・見出し・色だけをその場で書き換える（`layerBody` の `live()`）。
`tests/ui.js` は「動かした後も同じ摘みが画面に残っていて、続けて動かせるか」を見ている。

### 9. 数値欄が見切れた

`input[type=range]` には既定で 130px ほどの最小幅があり、`flex:1` にしても縮まない。
名前＋摘み＋数値欄の合計が層の枠より広くなり、右端の数値欄が切れていた。
→ 摘みを `flex:1 1 0; width:0; min-width:40px` にして縮ませ、名前と数値欄は `flex:none`。
上のバーの数値欄も `min-width:0` にすると狭い画面で潰れるので、`flex:none` にしてある。
**見た目の崩れは Node の検査では落ちない。** 1280px と 1024px で headless Chrome のスクリーンショットを撮って確かめる
（`?fresh=1&demo=photo&sel=1` で層を選んだ状態で開ける）。

### そのほか

- **`*.vbs` は UTF-16LE(BOM)。** UTF-8 だと日本語が壊れて起動しない。
  **文字コードだけ見て中身を見ないと一度やらかす** ― `tests/ui.js` は
  起動行 `shell.Run """" & target & """"` の引用符が潰れていないかも見ている
- Bash の heredoc は長いと途中で切れる。`""` を含む長いテキストは Write/Edit ツールで書く
- 指数が振り切れないように `exp` の中身は ±80 で挟む（exp(80)=5e34。これ以上は物理でなく数値の話）
- ニュートン法の更新は 1V で頭打ちにする（減衰）。外すと発散する

### 何を見ているか

**`tests/run.js` は「それらしい」では通さない。解析解と突き合わせる。**

- ビルトイン電位が `Vt·ln(Na·Nd/ni²)` と一致する（2mV 以内）
- 空乏層幅が空乏近似と 7% 以内（差はデバイ長ぶんの裾。逆バイアスを深くすると縮む
  ことまで確かめている）
- `∫E dx = −(電位差)`、`ε·Emax = 片側の全電荷`（ガウスの法則）、全体が中性
- n 側の少数キャリアが `(ni²/Nd)·exp(V/Vt)` になる（ショックレーの境界条件）
- MOS の Vth・VFB が、ポアソンで探した値と教科書の式で一致する（5mV 以内）
- S値が室温の下限 60mV/dec を割らない
- ダイオードの理想係数が、低電圧で >1.2・中ほどで 1.00・高電流で >1.5 になる
- 光子の収支が合う（拾った＋逃した＝入った）
- **青は表面再結合で落ちるが厚みでは落ちない／赤は厚みで落ちるが表面では落ちない**

**`tests/quest.js` はお手本が通ることだけでなく、通ってはいけないものが
通らないことも見る。** 空の作業台・ただの一片・他の課題のお手本。

ここで2度、間違った不変条件を書いて外した:

1. 「どの課題も、他のお手本の半分以上では落ちること」
   → 後の章のお手本はどれも pn 接合なのだから、「はじめての接合」も「整流する」も満たす。当たり前だった
2. 「前の章のお手本では通らないこと」
   → 第2章の逆バイアスのダイオードはそのまま整流するし、p⁺ が薄ければ 400nm も拾う。
   **章が上がっても必要な構造が増えるとは限らない** ― 増えるのは「何を見るか」のほう

通すために閾値をいじるのは、物理ではなく採点を歪める。今課しているのは
「全体として緩すぎない」「どの課題も何かは見分ける」「**構造の前提は必ず要る**」の3つ。

**`tests/ui.js` は本物の `index.html` から DOM を組んで、本物の `ui.js` を Node で動かす。**
id の書き間違いと「置く→解く→描く→採点」の一巡がここで落ちる。消さないこと。
全22問について「お手本を出す→採点する」を画面ごしに通している。
