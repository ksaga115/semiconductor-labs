# 特性ラボ ― 謎の素子を測って、パラメータを当てる

`index.html` をブラウザで開くだけで動く（`起動.vbs` をダブルクリックでもよい）。
参考書は [第2部 デバイスの基礎](../第2部_デバイスの基礎.html)。
SemiLab が第2部の「作る」側なら、ここは**「測る」側** ― デバイス評価・工程モニタの入口。

## なにをするラボか

謎の素子が6つある: **ダイオード D**・**MOSFET M**・**MOS 容量 C**（第1〜3章）と、
第4章の **温度を振ったダイオード TD**・**濃度に段のある p⁺n 接合 P**・**2 成分のダイオード R**。
画面には測定表と特性曲線だけが出る。そこから電卓ひとつでパラメータを抽出し、
答案の欄に書き込んで採点にかける。採点は真の値との差だけを見る（PixelLab の
「謎のカメラ」と同じ measure 型。真値は `src/char.js` に書いてある ― 見たければ見ればいい。
課題の価値は答えの数字ではなく、**曲線から数字を取り出す手つき**にある）。

## 課題（4章13問）

| 章 | id | 当てるもの | 手つき |
|---|---|---|---|
| D | dn | 理想係数 n（±0.06） | 片対数の傾き: n = ΔV/(Vt·ln(I₂/I₁)) |
| D | dis | 飽和電流 Is（×/÷1.6） | 直線を V=0 へ外挿: Is = I/e^(V/nVt) |
| D | drs | 直列抵抗 Rs（±25%） | てっぺんの寝た分: Rs = (V − nVt·ln(I/Is))/I |
| M | mvth | しきい値 Vth（±0.03V） | 線形領域の直線を横軸へ外挿 |
| M | mk | µCox·W/L（±15%） | 同じ直線の傾き ÷ Vd |
| M | mss | S 値（±8 mV/dec） | 裾の 1桁あたりのゲート電圧 |
| C | ctox | 酸化膜厚 tox（±0.4nm） | 蓄積の棚: tox = εox/Cox |
| C | cna | 基板濃度 Na（×/÷1.5） | 反転の棚: Wdmax = εs(1/Cmin−1/Cox) → Na |
| C | cvfb | フラットバンド Vfb（±0.15V) | 棚を離れる肩の位置 |
| TD | teg | 見かけの Eg（±0.025 eV） | ln(Is/T³) を 1/T に対して引いた傾き × k（≈1.203 eV） |
| P | cvn | 浅い濃度 N1（×/÷1.2）と Vbi（±0.05 V） | 1/C² の直線の傾き 2/(qεsN) と横軸の交点 |
| P | cvx | 段の深さ x1（±0.05 µm）と深い濃度 N2（×/÷1.2） | 2点ずつ微分して N(W)、W = εs/C |
| R | rec | Is2（×/÷1.3）・Is1（×/÷1.15）・Vx（±0.01 V） | 低い V の n=2 から Is2、高い V で Is2 を引いて Is1、Vx = 2Vt·ln(Is2/Is1) |

第4章は「1本の曲線の奥」を読む章。
- **teg**: 答えは 300 K の Eg（1.12 eV）ではない。Eg が温度で下がるので、アレニウスの傾きが教えるのは
  Eg(T) の接線を 0 K まで延ばした値（≈1.20 eV）。T³ で割り忘れると 3kT ぶん（≈0.08 eV）大きく出る ― どちらも落ちる。
- **cvx**: 段をまたぐ組（−1.5〜−2 V）の 1.17×10¹⁶ は、2つの濃度が混ざった値なので N2 ではない。
- **rec**: 0.70 V の点をそのまま Is1 と読むと、n=2 の成分が混ざって 1.26 倍大きく出る（許容の外）。先に Is2 を引く。

白紙の答案では 1 問も通らない。許容の外（n を 0.14 外す、Å と nm を取り違える、
傾きを Vd で割り忘れる、など定番の失敗）はきちんと落ちる。

## 数字はどこから来たか

- **測定は全部教科書の式**から機械が生成する（乱数なし ― 同じ表が毎回出る）:
  - ダイオード: I = Is(e^((V−IRs)/nVt)−1) を二分法で解く。真値 Is=2×10⁻¹³ A・n=1.36・Rs=4.7Ω
  - MOSFET: Id = µCox(W/L)·Vd·ζ、ζ = mVt·ln(1+e^((Vg−Vth)/mVt))（弱⇄強反転の標準補間）。
    真値 Vth=0.62V・µCoxW/L=3.2×10⁻⁴ A/V²・S=92mV/dec、Vd=50mV
  - MOS C-V（高周波・理想）: 蓄積 Cox=εox/tox、空乏 Cox/√(1+2Cox²(Vg−Vfb)/(qNaεs))、
    反転で Cmin に張り付く。真値 tox=4.2nm・Na=3×10¹⁷cm⁻³・Vfb=−0.9V
  - 温度を振ったダイオード TD: Is(T) = C0·T³·exp(−Eg(T)/kT)、Eg(T) は SemiLab と同じ Varshni
    （1.17 − 4.73×10⁻⁴T²/(T+636)、300 K で 1.1245 eV）。Is(300 K) = 1×10⁻¹² A、250〜400 K を 25 K おき。
    採点の真値は表の全点の最小二乗で出した見かけの Eg = 1.203 eV（2点法でも同じ値になる）
  - 段のある p⁺n 接合 P: Na = 10¹⁹ / n 側は接合から 0.6 µm まで N1 = 1×10¹⁶、その先 N2 = 3×10¹⁶。
    片側階段接合の空乏近似で、電位差 = (q/εs)∫₀ᵂ x·N(x) dx を W について解き C = εs/W。Vbi = 0.893 V
  - 2 成分のダイオード R: I = Is1(e^(V/Vt)−1) + Is2(e^(V/2Vt)−1)、Is1 = 1×10⁻¹⁴ A、Is2 = 2×10⁻⁹ A、Vx = 0.631 V
- **SemiLab との突き合わせ**（`tests/run.js`）: Eg(T) は SemiLab の `phys.eg` と一致、Is(T)/Is(300 K) は
  SemiLab の (ni(T)/ni(300 K))² と一致、一様な濃度の接合容量は SemiLab のダイオードの `cap(V)` と 0.3% 以内で一致
  （差は p⁺ 側の空乏のぶん）。
- **定数は 300K・Si の教科書値**: Vt=25.852mV、ni=10¹⁰cm⁻³、εs=11.7ε₀=1.036×10⁻¹²F/cm、
  εox=3.9ε₀=3.45×10⁻¹³F/cm（Sze の表と同じ）。
- `tests/run.js` は**課題が教える抽出手順そのものを機械が実行し、真値が返る**ことを確かめている
  （n・Is・Rs・Vth・µCoxW/L・S・tox・Na すべて）。表と手順のあいだに嘘がない、の検査。

## モデルの外（正直な線引き）

- ダイオード: 並列（漏れ）抵抗・高注入・温度依存はなし。n は電圧域で変わらない一定値。
- MOSFET: 移動度劣化・−Vd²/2 の項・ボディ効果はなし。だから外挿の切片がちょうど Vth になる
  （実物は測り方の流儀 ― 最大 gm 法・定電流法 ― で数十 mV 動く。データシートの Vth に測定条件が添えてある理由）。
- C-V: 高周波・理想（界面準位ゼロ・ゲート空乏なし・少数キャリアは追従しない）。
  低周波 C-V が反転で Cox に戻る話・界面準位でなだらかになる話はモデル外。
- 実測の C-V/I-V にはノイズとオフセットが乗る ― このラボの表はきれいすぎる。
- TD: 拡散係数と拡散長の温度依存（D/L の T 依存）は入れていない。入れると T の指数が 3 からずれ、読める見かけの Eg が
  数十 meV 動く。低温で生成電流（ni ∝ exp(−Eg/2kT)、見かけの値がほぼ Eg/2）が支配する域も入れていない ―
  実物のダイオードで温度を振るときは、どちらの電流が効いている域かを先に確かめる。
- P: 空乏近似なので段は鋭い。実測の C-V プロファイルは段をデバイ長（1×10¹⁶ で約 41 nm）の数倍の幅でなまらせ、
  段の近くでは N(W) が本当の濃度とずれる。p⁺ 側の空乏（0.1% 級）も無視している。
- R: 直列抵抗は無視できる小ささと仮定（第1章の D と違って、てっぺんが寝ない）。

## 検査

```
node tests\all.js
```

- `tests/run.js` ― 式が教科書どおりか＋**抽出手順の往復**（表→手順→真値が返る）。
- `tests/quest.js` ― お手本で通る・白紙で落ちる・許容の外と単位の取り違えが落ちる。
- `tests/ui.js` ― 本物の index.html と ui.js を Node の DOM 模型で動かし、記入→採点→保存の一巡。

## ここから先
