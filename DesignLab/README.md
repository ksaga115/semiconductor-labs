# 設計ラボ ― 1 台の装置を、光子から数字で設計する

第10部『[設計演習](../第10部_設計演習.html)』のラボ。
**原始部品 ＝ 予算表（掛け算の光の予算と、二乗和の雑音の予算）**。
微弱光カメラ・LiDAR・分光器の 3 つの装置について、光源・光学・検出器・読み出し・伝送・冷却・校正の数値を決めると、
信号の電子数・SN 比・1 パルスの検出数・背景と SPAD の飽和・距離の精度・センサの上の波長の位置・分解能・吸光度の雑音がその場で出る。
課題はそれを要求に収める設計問題（3章12問）。ブラウザだけで動く（依存ゼロ・通信ゼロ・乱数ゼロ）。

```
カメラ   光子/s × 集める (1−cosθ)/2 × 透過 × QE × 露光 ──→ S
         S, 背景, 画素数·σr² ──→ SN 比 = S/√(S+B+nσr²)（sCMOS）・S/√(2(S+B))（EM-CCD、F² = 2）
         飽和/2^bit ──→ 1 LSB　　画素×bit×枚/秒 ──→ Gb/s　　Qmax(1−ΔT/ΔTmax) ──→ TEC の吸熱
LiDAR    パルスの光子 × ρ/π·A/R² × 透過 × 検出効率 ──→ 1 パルスの検出数
         E_sun·Δλ·ρ/π·A·Ω ──→ 背景 ──→ r·τd（SPAD の飽和）
         c·√((幅/2.355)² + 揺らぎ²)/2 ÷ √N ──→ 距離のばらつき
分光器   mλ = d(sin α + sin β) ──→ x = f·tan(β − β中心) ──→ センサに収まるか
         逆線分散 × max(スリット, 2 画素) ──→ 分解能の目安　　スリット×角度 ──→ 入る光
         0.434/√(電子×回数) ⊕ 傾き×校正の残差 ──→ 吸光度の不確かさ
```

## 起動

`起動.vbs` をダブルクリック（`index.html` を直接開いてもよい）。
`?fresh=1` で最初から、`?quest=prec` で課題を選んだ状態で開く。

## 画面

- **左** ― 装置の 52 個の数値（カメラ・LiDAR・分光器の小見出しで区切ってある）と、そこから出る数字。
  既定値は第10部の基準の設計（245 e⁻・SN 比 13.9・29.6 個・12.1 mm …）。
- **真ん中** ― 4 枚の動く図。どれも採点と同じ `sys.evaluate` の式から描く。上のバーの「動きを止める」で止められる。
  - **光の予算**（左上）― 分子の光子 → 集める → 光学系 → 電子 → 1 露光を対数の棒で並べ、
    **最初の段の 36 粒に対して各段の率の比だけの粒**が流れる。いちばん大きく減る段が、粒の減り方で見える。
  - **SN 比と信号**（右上）― sCMOS と EM-CCD の曲線、交差点（S + B = 画素数 × σr²）、今の設計の点（脈打つ）。
  - **LiDAR の到着時刻**（左下）― 1 ns のビンに、反射の山（σ = 1 光子のばらつきのガウス）と背景の床の**期待値**が
    1 パルスずつ積もる。k パルスでの SN 比（1 パルスの √k 倍）を表示する。
  - **分光器のセンサ**（右下）― センサの長さの上に 100 nm ごとの波長の位置 x(λ)、2 次の重なる帯、
    範囲を往復する走査線と分解能の幅、その波長の 2 次が落ちる場所（破線）。
    下の段に 2 つの予算の内訳 ― 入る光（スリット × 角度、掛け算）と、吸光度の不確かさ（ショット雑音と波長のずれ、二乗和）。
- **右** ― 課題。採点は設計から出た数字だけを見る。

## 課題 ― 3章12問

| # | id | 名前 | 何を踏むか |
|---|---|---|---|
| | | **第1章　微弱光カメラ** | |
| 1 | `fast` | 5 ms で SN 比 10 | 露光を半分にすると 9.46。透過（≤ 0.7）と量子効率（≤ 0.95）の掛け算で取り戻す |
| 2 | `dark` | 暗い輝点は EM-CCD | 交差点 23 e⁻ より暗い輝点。EM-CCD なら 13.1 ms から、sCMOS は 19.3 ms で窓の外 |
| 3 | `data` | 180 枚/秒を 1 本の線で | 1 LSB ≤ σr/2 に 16 ビット、CXP-12 1 本に収まるのは 186 枚/秒まで |
| 4 | `tec` | 10 秒の露光で暗電流を床の下へ | 冷やすほど暗電流は減り、TEC の吸熱も減る ― ΔT の窓は 47.6〜59.5 K |
| | | **第2章　LiDAR** | |
| 5 | `range` | 300 m で 1 パルス 30 個 | 1/R² を受光口の面積で取り戻す。37.8 mm 以上・50 mm まで |
| 6 | `sun` | 昼の背景で SPAD を飽和させない | 背景 ∝ Δλ·Ω。フィルタ ≥ 5 nm・視野 ≥ 0.03° の下限つきで r·τd ≤ 0.3 |
| 7 | `dead` | 不感時間を選ぶ | アフターパルスの下限 5 ns と、飽和の上限 11.1 ns |
| 8 | `prec` | 200 m で 2 cm を 0.1 ms で | 256 光子 → 9 パルス。時間とあいまいさのない距離（c/2f ≥ 300 m、499.6 kHz まで）の上限 |
| | | **第3章　分光器** | |
| 9 | `grat` | 格子の本数で範囲と分解能を両立 | 約 408 本/mm から 2.45 nm 以下、約 421.5 本/mm を超えると 1,000 nm がはみ出す |
| 10 | `slit` | スリットで明るさを稼ぐ | 入る光 10% には 48.7 µm、分解能 2.5 nm は 50 µm（2 画素）まで |
| 11 | `absorb` | 吸光度の雑音を 1×10⁻⁴ に | 189 回以上の平均、1 秒以内は 200 回まで |
| 12 | `calib` | 波長の目盛りまで含めた不確かさ | 校正の残差 0.05 nm のまま、傾き 0.0035 AU/nm 以下の場所で測る |

条件を固定する課題は、**固定した欄を動かすと数字が届いていても落ちる**
（分子を明るくする・背景を減らす・TEC を大きくする・尖頭値を上げる・スリットを細くする、の類は反則として採点される）。
窓のある課題は**両側**が落ちる。

## 数字はどこから来たか

| 量 | 式 | 出どころ |
|---|---|---|
| 集める割合 | (1 − cos θ)/2、θ = asin(NA/n) | 第10部 02・第7部 02（等方的な発光と仮定） |
| 信号 | 光子/s × 集める × 透過 × QE × 露光 | 第10部 02（2×10⁵ /s は仮定） |
| SN 比 | sCMOS: S/√(S + B + nσr²)、EM-CCD: S/√(2(S + B)) | 第10部 03・第5部 04（F² = 2） |
| 暗電流 | dark25 · 2^(−ΔT/9) | 第10部 04・第2部 03（約 9 ℃ で 2 倍、冷やす前 10 e⁻/画素/s は仮定） |
| 1 LSB・DR | 飽和/2^bit、20 log(飽和/σr) | 第10部 04・第6部 09 |
| データ | 画素 × bit × 枚/秒 | 第10部 04 |
| TEC | Qmax(1 − ΔT/ΔTmax) | 第10部 04・第8部 05 |
| 1 パルスの検出数 | E/hν × ρ/π·A/R² × 透過 × 検出効率 | 第10部 05（ランバート面、往きは広がらない） |
| 背景 | E_sun·Δλ·ρ/π·A·Ω / hν × 透過 × 検出効率、Ω = ifov² | 第10部 06（0.3 W/(m²·nm) は仮定） |
| 飽和 | r·τd、数えられる率 r/(1 + r·τd) | 第10部 06（麻痺しない型） |
| SN 比（LiDAR） | N/√(N + 床)、床 = 背景 × パルス幅、積むと √(パルス数) 倍 | 第10部 06 |
| 距離のばらつき | c·√((幅/2.355)² + 揺らぎ²)/2 ÷ √N | 第10部 07・第0部 02 |
| センサの上の位置 | mλ = d(sin α + sin β)、x = f·tan(β − β中心) | 第10部 08・第7部 11 |
| 分解能の目安 | 逆線分散 d·cos β/f × max(スリットの像, 2 画素) | 第10部 08（スリットの像の幅と、ナイキストの 2 画素の大きいほう） |
| 入る光 | (スリット × コア)/(π/4 · コア²) × (NA分光器/NAファイバ)²、NA分光器 = 1/(2F) | 第10部 08・第7部 06（コアは一様に光ると仮定） |
| 吸光度 | δA = 0.434/√(電子 × 回数)、波長のずれ = 傾き × 残差、二乗和 | 第10部 09・第8部 10 |

乱数は使わない ― 同じ設計は必ず同じ数字になり、採点も毎回同じ。
図の粒の位置も、黄金比の低食い違い列で決めている（毎回同じ絵）。

## モデルの外（正直な線引き）

- **点像の形・画素の間の電荷の漏れ・画素ごとのばらつき（PRNU/DSNU）は入れていない。** 輝点は「画素数」で一様に広がると見る。
- EM-CCD の増倍率そのもの・クロック誘起電荷・光子計数モードは入れていない（F² = 2 の近似だけ）。
- 暗電流の「9 ℃ で 2 倍」は生成電流の目安。拡散電流が支配する温度では傾きが変わる。
- LiDAR のパイルアップの形・同時計数・時間のゲート・大気の減衰・雨や霧・物体の傾きは入れていない。
  背景は r·τd と窓の中の平均の数で見るだけで、ヒストグラムの図も**期待値**（揺らぎのない平均）を積んでいる。
- **目の安全（IEC 60825-1 の AEL）は計算しない** ― 規格の手順で必ず計算し直す項目（第8部 12）。
- 格子の効率の波長依存・迷光の分布・収差・スリットの高さとセンサの画素の高さの関係は入れていない。
  分解能は「目安」で、実際の装置の線の形（台形・収差）で数 % 〜数十 % 変わる。
- 吸光度の不確かさはショット雑音と波長のずれの 2 成分だけ。ランプの揺らぎ・暗電流の引き算・迷光（A ≈ 3 で頭打ち）は入れていない。

## ここから先

- EM-CCD の光子計数モード（しきい値で 0/1 に切る）と、1 フレーム 1 個までの数え落とし
- LiDAR のパイルアップの補正（Coates の式）と、同時計数による背景の抑え込み
- 分光器の線の形を、スリットの像と画素の畳み込みとして計算する版（分解能の目安を置き換える）
- カメラの MTF とナイキスト ― 輝点の画素数を倍率と画素の大きさから出す
- 3 つの装置の信頼性の予算（第8部 02・03 の加速とワイブル）を課題にする
