# 品質ラボ ― FIT・加速試験・熱設計・Cpk を「数字で」設計する

`index.html` をブラウザで開くだけで動く（`起動.vbs` をダブルクリックでもよい）。
参考書は [第8部 信頼性と品質](../第8部_信頼性と品質.html)。ここはその演習場で、
信頼性・熱・ばらつきの数字を自分で決めて、採点にかける。

## なにをするラボか

信頼性や品質の仕事は「壊れないことを祈る」仕事ではなく、
**寿命・温度・ばらつきを数字で請求し合う**仕事になる。このラボの模型は次の 5 つの束でできている。

1. **FIT と MTTF** ― 部品ひとつの故障率 λ[FIT] と直列部品数 n から、系の MTTF = 10⁹/(λ·n) 時間。
2. **アレニウス加速** ― AF = exp(Ea/k · (1/Tuse − 1/Tstr))。使用温度で 10 年ぶんの保証を、
   高温試験なら何時間で済ませられるか（試験時間 = 寿命/AF）。
3. **ワイブル** ― 形状 m と尺度 η から B10 = η(−ln 0.9)^{1/m}。m<1 は初期不良、m>1 は摩耗。
4. **熱設計と TEC** ― Tj = Tamb + P·(θjc+θcs+θsa)。TEC は Qc = Qmax(1 − ΔT/ΔTmax) の直線で、
   欲しい温度差と吸える熱がトレードオフになる（第5部「冷却の請求書」の支払い窓口）。
5. **Cpk と誤差伝播** ― Cpk = (規格幅 − |ずれ|)/3σ、不良率 ppm は正規分布 Φ から。
   独立な誤差は σtot = √(σ1²+σ2²) で足す。

## 数字はどこから来たか

- **AF ≒ 78（0.7eV, 55→125 ℃）／≒ 260（55→150 ℃）** ― k = 8.617×10⁻⁵ eV/K で
  exp を手計算すれば出る定番値。検査 `tests/run.js` が両方を数値で確かめている。
- **Ea = 0.7 eV** は「よく使われる代表値」であって物性定数ではない。故障モードごとに
  0.3〜1.2 eV ほど幅がある（JEDEC JEP122 参照）。課題で Ea を固定しているのはそのため
  ―― Ea を盛れば試験は一瞬で終わるが、それは加速したのではなく仮定を変えただけ。
- **Cpk = 1 ↔ 2700 ppm、Cpk = 1.33 ↔ 63 ppm** ― 正規分布の両側裾。Φ は
  Abramowitz–Stegun 7.1.26 の erf 近似（誤差 1.5×10⁻⁷）で計算しており、
  Φ(0)=0.5、Φ(3)=0.99865、Φ(1.96)=0.975 を検査で確認している。
- **B10 = η(−ln 0.9)^{1/m}** ― 不信頼度 F(t)=1−exp(−(t/η)^m) を 0.10 で解いただけ。
- **85/85・1000h ≒ 10年** ― Peck の AF = (RH比)ⁿ×アレニウス。n=3・Ea=0.79 eV（Peck 1986 の原典値 n=2.7 を慣例で 3 に丸めたもの。n=2.7 なら AF≒101）で
  使用 40℃/60%RH に対し (85/60)³×exp(…) ≒ 2.8×40 ≒ **113 倍** → 87,600h/113 ≒ 778h。
  n と Ea は故障モード依存（JEP122）― 課題で固定しているのはアレニウスの Ea と同じ理由。
- **温度サイクルの AF = (ΔT比)²** ― Coffin-Manson 寿命 ∝ ΔT⁻ⁿ の n=2（はんだの代表値）。
  −40〜125℃（ΔT165K）は 1日1回・ΔT30K の使用に対し (165/30)² ≒ 30 倍の回数早送り。
- **HAST 96h ↔ THB 1000h** ― JESD47 は THB 85℃/85%RH 1000h の代替として HAST 130℃/85%RH 96h
  （BGA などは 110℃ 264h）を挙げている。85→130℃ の純アレニウス（0.79eV）は 17.4 倍で、
  1000/17.4 ≒ 57h ― 規格の 96h はそれより長い（安全側）。検査が 17.4 を数値で確かめている。
- **%GR&R = 6σ_meas/(規格幅)、10%/30% の線** ― AIAG MSA の目安。繰り返しと再現性は二乗和なので、
  片方だけ磨いても床が残る（このラボの誤差伝播と同じ会計）。
- **管理図の ARL** ― 3σ の空振り 0.27%（370 群に 1 回）、n=5 で 1σ のずれは 4.5 群。群の平均の σ は σ/√n（第8部 09）。
  Φ は上の erf 近似で、検査が ARL₀ = 370・ARL₁ = 4.5 を確かめている。
- **不確かさの予算** ― 第8部 10 の光パワーメータの例（U 2% の校正・分解能 ±0.5%・繰り返し 0.5%・温度 ±0.2%）そのもの。
  校正 2% のままでは平均を何回しても U ≈ 2.1% が床になる。
- **Norris-Landzberg** ― AF = (ΔTs/ΔTu)^n·(fu/fs)^m·exp(Ea/k·(1/Tmax,u − 1/Tmax,s))。定数 n = 1.9・m = 1/3・Ea/k = 1414 K は
  Norris & Landzberg, IBM J. Res. Dev. 13, 266 (1969) の SnPb はんだ（C4）の値で、JEDEC JEP122 にも同じ形で載っている。
  鉛フリー（SAC）には別の定数が報告されていて、定数は材料と実装の形で変わる ― 課題で固定しているのは仮定だから。
  使用 ΔT 30 K・1 回/日・最高 55 ℃ を −40〜125 ℃ で試すと、同じ周波数なら AF 54.4（ΔT の項 25.5 × 最高温度の項 2.13）、
  24 回/日で 18.9（194 回・8.1 日）、36 回/日で 16.5（222 回・6.2 日）。周波数を 8 倍にすると AF は 1/2。
  cm 課題の純 Coffin-Manson（n = 2・30 倍・121 回）とは定数も補正も違う別のモデルで、どちらが正しいかではなく、どこまで入れるかの違い。
- **ndc = 1.41·σ部品/σ測定（切り捨て）** ― AIAG MSA 第4版の有効区分数。5 以上を求める。全変動比 x = σ測定/√(σ測定² + σ部品²) とは
  ndc ≈ 1.41·√(1−x²)/x の関係（検査で確かめている）。σ繰り返し 0.005・再現性 0.006・部品 0.03 で ndc 5（5.42）・公差比 7.8 %・全変動比 25 %。
- **OC 曲線** ― 1 回抜き取り (n, c) の合格の確率は二項分布の累積。AQL 1 %・LTPD 5 %・α 5 %・β 10 % の定番の計画 n = 132・c = 3 で
  α 4.43 %・β 9.92 %。c ≤ 2 では n をいくつにしても両立しないことを、検査が n = 1000 まで全探索で確かめている。
  JIS Z 9015-1（ISO 2859-1）は AQL で索引する表と、きつい／なみ／ゆるいの切り替えの規則を持つ方式で、ここではその骨格（1 回の OC）だけ。
- **TM-21** ― IES LM-80 の光束維持率の測定を Φ(t) = B·exp(−αt) に当てはめ、Lp = ln(B/p)/α。外挿は試験時間の 6 倍（試料 20 個以上、10〜19 個は 5.5 倍）まで（IES TM-21-11）。
  1,000 h 99.0%・6,000 h 97.0% の仮の点で α 4.08×10⁻⁶ /h・B 0.994・L70 85,900 h・L90 24,400 h・L80 53,200 h（第8部 17 と同じ）。
- **冗長** ― 2 台並列（ホットスタンバイ）の MTTF 1.5/λ、修理 1 か所の並列 (3λ+μ)/(2λ²)、多数決 3R²−2R³（R ＞ 0.5 でだけ単体より良い）。
  λ = 2×10⁻⁵ /h で MTTR 24 h なら 5.2×10⁷ h、168 h なら 7.5×10⁶ h、5 年の生存率は単体 41.6%・並列 65.9%・直列 17.3%、入れ替わり 3.96 年（第8部 18）。
- **要因計画の回数** ― 2² 計画の効果の標準誤差 2σ/√N、両側 5% の検出力 Φ(Δ/SE−1.96)+Φ(−Δ/SE−1.96)。80% には N ≥ (5.6σ/Δ)²（第8部 16）。
- **TEC の直線** ― Qc は ΔT=0 で Qmax、ΔT=ΔTmax で 0 になる一次近似。
  実物の性能曲線は電流にも依るが、一次近似でもトレードオフの形は正しく出る。

## モデルの外（正直な断り書き）

- 故障率一定（指数分布）は**バスタブの底**だけの話。初期不良とワイブル摩耗は別式で、
  このラボでも m で区別するが、ひとつの系に混在する現実はモデル外。
- 加速は温度（アレニウス）・湿度（Peck）・温度サイクル（Coffin-Manson）の3本。
  電圧・電流密度の加速と、これらの**組み合わせ**（サイクル＋湿度など）はモデル外。
  Coffin-Manson の周波数と最高温度の補正は Norris-Landzberg（nl 課題）で入れたが、保持時間（ドウェル）と
  ひずみ速度の効き、鉛フリーの定数はモデル外。
- θ（熱抵抗）一定は一次元定常の近似。過渡熱抵抗・熱の広がりはモデル外。
- Cpk の ppm 換算は正規分布仮定。裾が正規から外れる工程では ppm は当てにならない。
- 管理図は正規・独立なデータの X̄ 図で、限界外の 1 点のルールだけ（連のルール・EWMA・CUSUM はモデル外）。
  不確かさは相関のない成分の一次の合成で、自由度の補正（ウェルチ・サタースウェイト）は入れていない。
- GR&R は繰り返し/再現性/部品のばらつきの**成分を与えて**、公差比・全変動比・ndc を出すところまで。
  その成分を測定のデータから推定する分散分析の表（部品×測定者×繰り返し、交互作用の分離）はモデル外 ― 実務の様式は AIAG MSA の手順書で。
- TM-21 は 2 点からの指数関数だけで、当てはめに使う区間の規則（試験の最後の 5,000 h）と信頼区間は入れていない。冗長は独立な故障で、共通原因・修理の失敗・切り替えの失敗は入れていない。
  要因計画は 2² の全実施だけで、一部実施の交絡・分散分析の表は入れていない。検出力は σ が既知の正規近似。
- 抜き取りは 1 回抜き取りの二項分布だけ。2 回・多回の抜き取り、ロットの大きさの効き（超幾何分布）、
  JIS Z 9015 の切り替えの規則はモデル外。

## 検査

```
node tests\all.js
```

  Norris-Landzberg の 54.4/18.9、ndc 5.42 と全変動比の関係、OC の手計算の値と (132, 3) の α・β、
  TM-21 の L70 85,900 h と上限 36,000/33,000 h、冗長の 7.5×10⁴/5.2×10⁷/7.5×10⁶ h と 3.96 年、要因計画の 1.41 nm と検出力 85%）。
