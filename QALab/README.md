# 品質ラボ ― FIT・加速試験・熱設計・Cpk を「数字で」設計する

`index.html` をブラウザで開くだけで動く（`起動.vbs` をダブルクリックでもよい）。
参考書は [第8部 信頼性と品質](../第8部_信頼性と品質.html)。ここはその演習場で、
信頼性・熱・ばらつきの数字を自分で決めて、採点にかける。

## なにをするラボか

信頼性や品質の仕事は「壊れないことを祈る」仕事ではなく、
**寿命・温度・ばらつきを数字で請求し合う**仕事になる。このラボの模型は次の 5 つの束でできている。

1. **FIT と MTTF** ― 部品ひとつの故障率 λ[FIT] と直列部品数 n から、系の MTTF = 10⁹/(λ·n) 時間。
2. **アレニウス加速** ― AF = exp(Ea/k · (1/Tuse − 1/Tstr))。使用温度で 10 年ぶんの保証を、
   高温試験なら何時間で済ませられるか（試験時間 = 寿命/AF）。
3. **ワイブル** ― 形状 m と尺度 η から B10 = η(−ln 0.9)^{1/m}。m<1 は初期不良、m>1 は摩耗。
4. **熱設計と TEC** ― Tj = Tamb + P·(θjc+θcs+θsa)。TEC は Qc = Qmax(1 − ΔT/ΔTmax) の直線で、
   欲しい温度差と吸える熱がトレードオフになる（第5部「冷却の請求書」の支払い窓口）。
5. **Cpk と誤差伝播** ― Cpk = (規格幅 − |ずれ|)/3σ、不良率 ppm は正規分布 Φ から。
   独立な誤差は σtot = √(σ1²+σ2²) で足す。

## 課題（3章8問）

| 章 | id | 課題 | 効かせどころ |
|---|---|---|---|
| 寿命 | mttf | 系の MTTF を 20 年に | 部品 FIT を下げる（n=100 固定） |
| 寿命 | series | 部品点数で寿命を買う | 直列数を減らす（FIT=50 固定） |
| 寿命 | accel | 10 年保証を 500 時間で | 試験温度を上げる（Ea=0.7eV 固定） |
| 寿命 | weib | B10 ≥ 5000 h | η を確保する（m=2 固定） |
| 熱 | theta | Tj ≤ 85 ℃ | 放熱器 θsa を選ぶ（P=2W 固定） |
| 熱 | tec | 冷やしつつ吸う | ΔT の窓を探す（Qmax・負荷固定） |
| ばらつき | cpk | Cpk ≥ 1.33 | σ を絞る（規格・ずれ固定） |
| ばらつき | prop | 誤差の予算配分 | 支配項 s2 を削る（s1 固定） |

どの課題も**条件固定つき**で、固定を破れば数字が届いていても落ちる。
既定の設計では 1 問も通らない。トレードオフのある課題（tec）は両側で落ちる。

## 数字はどこから来たか

- **AF ≒ 78（0.7eV, 55→125 ℃）／≒ 260（55→150 ℃）** ― k = 8.617×10⁻⁵ eV/K で
  exp を手計算すれば出る定番値。検査 `tests/run.js` が両方を数値で確かめている。
- **Ea = 0.7 eV** は「よく使われる代表値」であって物性定数ではない。故障モードごとに
  0.3〜1.2 eV ほど幅がある（JEDEC JEP122 参照）。課題で Ea を固定しているのはそのため
  ―― Ea を盛れば試験は一瞬で終わるが、それは加速したのではなく仮定を変えただけ。
- **Cpk = 1 ↔ 2700 ppm、Cpk = 1.33 ↔ 63 ppm** ― 正規分布の両側裾。Φ は
  Abramowitz–Stegun 7.1.26 の erf 近似（誤差 1.5×10⁻⁷）で計算しており、
  Φ(0)=0.5、Φ(3)=0.99865、Φ(1.96)=0.975 を検査で確認している。
- **B10 = η(−ln 0.9)^{1/m}** ― 不信頼度 F(t)=1−exp(−(t/η)^m) を 0.10 で解いただけ。
- **TEC の直線** ― Qc は ΔT=0 で Qmax、ΔT=ΔTmax で 0 になる一次近似。
  実物の性能曲線は電流にも依るが、一次近似でもトレードオフの形は正しく出る。

## モデルの外（正直な断り書き）

- 故障率一定（指数分布）は**バスタブの底**だけの話。初期不良とワイブル摩耗は別式で、
  このラボでも m で区別するが、ひとつの系に混在する現実はモデル外。
- アレニウスは温度加速のみ。湿度（Hallberg–Peck）、温度サイクル（Coffin–Manson）、
  電圧加速は扱っていない。
- θ（熱抵抗）一定は一次元定常の近似。過渡熱抵抗・熱の広がりはモデル外。
- Cpk の ppm 換算は正規分布仮定。裾が正規から外れる工程では ppm は当てにならない。
- GR&R（測定系のばらつき）は誤差伝播の一項として触れるだけで、分散分析はしない。

```
node tests\all.js
```

- `tests/quest.js` ― お手本で通る・既定で落ちる・反則（固定破り）が落ちる・トレードオフ両側で落ちる。

## ここから先

- 湿度加速（85/85 試験と Peck 則）、温度サイクル（Coffin–Manson）を足すと加速試験の課題が立体になる。
- スクリーニング（バーンイン）で m<1 の初期不良集団を削る話は第8部の deep ノートにだけある。
- 参考: JEDEC JEP122（故障メカニズムと Ea 表）、JESD51（熱測定）、Montgomery, *Statistical Quality Control*。
