# レーザーラボ ― 光をつくる側を、数字で設計する

第9部『[光源とレーザー](../第9部_光源とレーザー.html)』のラボ。
**原始部品 ＝ 共振器の会計（利得 ＝ 損失）と、熱の光のスペクトル**。
黒体の温度・LED の効率・端面の反射率・共振器の長さ・動作温度・格子の周期・パルスの条件を数値で決めると、
可視の割合・しきい値・スロープ効率・出力・縦モードの間隔・DFB の波長・尖頭値がその場で出る。
第4章では、緩和振動で決まる直接変調の帯域・SHG の出力と位相整合の許容幅・ファイバへの結合効率も出る。
第5章では、輝線 2 本で合わせた目盛りの誤差・量子欠損の熱・輝度とファイバのエテンデュで決まる入る光の上限も出る。
課題はそれを仕様に収める設計問題（4章12問）。ブラウザだけで動く（依存ゼロ・通信ゼロ・乱数ゼロ）。

```
温度 T ──→ 山 2898/T µm・可視の割合（プランクを積分）
R₁, R₂, L, α_i ──→ 鏡の損失 ln(1/R₁R₂)/2L ──→ しきい値の利得・微分量子効率 ──→ スロープ効率 η_d·hν/q
I_th(T) = I_th25·exp((T−25)/T₀) ──→ 出力 P = スロープ × (I − I_th)
n_g, L ──→ 縦モード λ²/2n_gL　　n_eff, Λ ──→ λ_B = 2n_effΛ　　L_cav ──→ c/2L　　Δλ ──→ 0.441λ²/cΔλ
I − I_th ──→ f_R = D·√(I − I_th) ──→ 帯域 √(1+√2)·f_R　　L, P, δT ──→ P_2ω = κ·L·P²·sinc²(u)
w_LD × 倍率, w_ファイバ, 横ずれ d ──→ η = (2w₁w₂/(w₁²+w₂²))²·exp(−2d²/(w₁²+w₂²))
```

## 起動

`起動.vbs` をダブルクリック（`index.html` を直接開いてもよい）。
`?fresh=1` で最初から、`?quest=slope` で課題を選んだ状態で開く。

## 数字はどこから来たか

| 量 | 式 | 出どころ |
|---|---|---|
| 黒体の山 | λ_max = 2897.77 µm·K / T | ウィーンの変位則。第9部 01 |
| 可視の割合 | ∫₄₀₀⁷⁰⁰ B dλ / ∫ B dλ（0.1〜100 µm を対数の格子 4,000 点で積分） | プランクの式。2,856 K で 6.5%、3,200 K で 10.5% |
| LED | EQE = η_inj·IQE·η_extr、電力の効率 = EQE·hν/(qV) | 第9部 03 |
| しきい値の利得 | Γg_th = α_i + ln(1/R₁R₂)/(2L) | 第9部 04 |
| 前から出る割合 | (1−R₁)√R₂ / ((1−R₁)√R₂ + (1−R₂)√R₁) | Coldren ほか、2 つの端面への出力の分け方 |
| スロープ効率 | η_d·hν/q、η_d = η_i α_m/(α_i+α_m)（両端面の合計） | 第9部 05 |
| しきい値の温度 | I_th ∝ exp(T/T₀) | 第9部 05 |
| 縦モード | Δλ = λ²/(2n_gL) | 第9部 06 |
| DFB | λ_B = 2n_effΛ、λ(T) = λ_B + (dλ/dT)(T − 25) | 第9部 07 |
| モード同期 | f = c/(2L)、Δt = 0.441λ²/(cΔλ)、尖頭値 ≈ 0.94E/Δt | 第9部 09（ガウス形） |
| 緩和振動 | f_R = D·√(I − I_th)（D は仮定の 1.5 GHz/√mA）、減衰を無視した応答の −3 dB は √(1+√2)·f_R = 1.554 f_R | 第9部 05、Coldren ほか『Diode Lasers and Photonic Integrated Circuits』の小信号変調 |
| NRZ の帯域の目安 | 0.7 × ビットレート | 設計の慣用の目安（仮定） |
| SHG | P_2ω = κ·L·P²·sinc²(ΔkL/2)。弱い変換（励起が減らない）で、最適集光（Boyd–Kleinman）なら長さに比例 | 第9部 10、Boyd『Nonlinear Optics』。κ = 1.0 %/(W·cm) は仮定 |
| 位相整合の許容幅 | sinc² の半値は ΔkL/2 = 1.39156、許容幅（FWHM）× 長さ ＝ 一定（1.0 ℃·cm は仮定） | 同上 |
| ファイバ結合 | η = (2w₁w₂/(w₁²+w₂²))²·exp(−2d²/(w₁²+w₂²)) | ガウスのモードの重なり（Joyce & DeLoach, Appl. Opt. 23, 4187 (1984)）。1550 nm の単一モードファイバのモードフィールド径 10.4 µm（Corning SMF-28 の仕様の代表値） |

乱数は使わない ― 同じ設計は必ず同じ数字になり、採点も毎回同じ。

## モデルの外（正直な線引き）

- **利得のスペクトルの形・キャリアの寿命・線幅・チャープ・空間的なホールバーニングは入れていない。**
  スロープ効率は温度によらず一定としている（実物は高温で下がることが多い）。
- しきい値は「25 ℃ の値 × exp」で与え、利得とキャリア密度からは計算しない（レート方程式の定常解の結果だけを使う）。
- 黒体は理想の黒体（放射率 1）。タングステンの放射率と、実際のランプのガラスの透過は入れていない。
- モード同期は変換限界のガウス形のパルス。分散と非線形によるパルスの広がりはモデル外。
- 目の安全（IEC 60825-1）の判定は入れていない ― 規格の手順で計算する項目（第8部 12）。
- 緩和振動は減衰（K 因子）を入れていない。実物は減衰とチップの寄生容量で帯域が √(1+√2)·f_R より狭くなり、D も高温で下がる。ここでは D を温度によらず一定としている。
- SHG は弱い変換（励起が減らない）と、長さに比例する最適集光を仮定。強い変換での飽和・熱による位相のずれ・フォトリフラクティブは入れていない。
- ファイバ結合は円いガウスのモードどうしの重なりで、LD の楕円のモード・角度のずれ・端面の反射（Fresnel）・非点収差は入れていない。

## ここから先

- 利得のスペクトル（放物線近似）とキャリア密度からしきい値を計算する版（レート方程式を 1 段深く）
- 減衰（K 因子）を入れた変調の応答と、D を微分利得と活性層の体積から出す版（第4章は D を仮定で与えている）
- SHG の強い変換（励起の減少）と、複屈折の角度の位相整合
- 楕円の LD のモードと、アナモルフィックなレンズでの結合
