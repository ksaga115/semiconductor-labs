# アナログラボ ― W/L と電流で、利得・帯域・雑音を設計する

第6部『[アナログ回路](../第6部_アナログ回路.html)』（基準書: ラザビー）のラボ。
**原始部品 ＝ 二乗則の MOSFET 1個**（NandLab「電圧で見る」と同じ level 1）。
W/L・電流・抵抗・容量を数値で決めると、Vov・gm・利得・GBW・雑音がその場で出る。
課題はそれを仕様に収める設計問題（5章16問）。ブラウザだけで動く（依存ゼロ・通信ゼロ・乱数ゼロ）。

```
W/L, Id ──→ Vov = √(2Id/µCox·W/L) ──→ gm = 2Id/Vov ──→ |Av| = gm·(RD∥ro)
                    │                        │                  ro = 1/(λId)
             スイングの下の壁            GBW = gm/2πCL・雑音 √(4kTγ/gm)
```

## 起動

`起動.vbs` をダブルクリック（`index.html` を直接開いてもよい）。
`?fresh=1` で最初から、`?quest=gain` で課題を選んだ状態で開く。

## 画面

- **左** ― 設計の 33 個の数値（電源・λ・W/L・Id・RD・CL・Rf・PD 容量・Cf・入力電荷・SC・2 段目・ADC・DC-DC・第5章の TIA の入力の容量と GBW と Cf・ミラー・バンドギャップ）と、そこから出る数字。
- **真ん中** ― 4 枚の図（高さが足りなければ上の 2 枚）。**|利得| と RD**（上げても gm·ro の壁で頭打ち）、**GBW と 電力**（W/L 固定なら傾き 1/2 ― 電力4倍で帯域2倍しか買えない）、**TIA の |Z|/Rf**（Cf が小さいと山が立つ）、**バンドギャップ**（下がる V_BE と上がる PTAT の和）。どれも採点と同じ `analog.js` の式から描く。
- **右** ― 課題。採点は設計から出た数字だけを見る。

## 課題 ― 5章16問

| # | id | 名前 | 何を踏むか |
|---|---|---|---|
| | | **第1章　バイアスを置く** | |
| 1 | `bias` | Vov を狙って置く | W/L = 2Id/(µCox·Vov²) |
| 2 | `eff` | 電力で gm を買う | gm/Id = 2/Vov の効率 |
| | | **第2章　一段で増やす** | |
| 3 | `gain` | ソース接地で 10 倍 | gm·RD とスイングの取り合い |
| 4 | `gbw` | GBW を電力で買う | gm ∝ √Id の √ 則 |
| 5 | `gain2` | ro の壁 ― 素の利得 100 | gm·ro = 2/(λVov) |
| | | **第3章　受光の後段** | |
| 6 | `tia` | TIA の Rf を選ぶ | 帯域 1/(2πRfC) ⇄ 雑音 √(4kT/Rf)。窓は 7.4〜10kΩ |
| 7 | `charge` | チャージアンプ | Q/Cf と kTC ― PixelLab の変換ゲインと同じ算数 |
| 8 | `diff` | 差動対で 20 倍 | Adm = gm·RD。差動は利得ではなく同相除去を買う |
| 9 | `lownoise` | 2 nV/√Hz の初段 | √(4kTγ/gm)。雑音半分は gm 4倍 |
| 10 | `sc` | 抵抗を時間で作る ― SC | 1/(fC) と √(kT/C) ― 窓は両側から閉じる |
| 11 | `ota2` | 2段OTA | GBW=gm1/2πCc、第2極 gm2/CL、RHPゼロ gm2/Cc ― Cc の窓 |
| | | **第4章　変換と電源** | |
| 12 | `adc` | 標本化の容量を選ぶ | √(kT/C) ≤ LSB/√12 と駆動の上限。12 ビット・1 V で窓は 0.83〜2 pF |
| 13 | `buck` | 降圧 DC-DC のコイル | ΔI = (Vin−Vout)D/(Lf)。12→3.3 V・1 MHz で窓は 8〜22 µH |
| | | **第5章　写す・基準・受ける** | |
| 14 | `mirror` | ミラーの誤差を 0.1% に | 単純なミラーは λΔV = 5%。カスコードで λΔV/(gm·ro)、代金は Vov 1 個。窓は W/L 32.7〜200 |
| 15 | `bgr` | バンドギャップの傾きを消す | m·(k/q)·ln n = 2 mV/K。m ≤ 10 なら n ≥ 10。n = 16 で m 8.16〜8.58 |
| 16 | `tiacf` | 帰還容量で鳴きを止める | Cf = 0 で 79 倍の山。山 ≤ 5%・帯域 ≥ 1.2 MHz の窓は 148〜186 fF（最大平坦 178 fF で 1.25 MHz） |

条件を固定する課題は、**固定した欄を動かすと数字が届いていても落ちる**。
トレードオフの両側（RD の上げすぎ・Rf の下げすぎ・電流で殴る）も採点が正直に断る。

## 数字はどこから来たか

| 量 | 式 | 出どころ |
|---|---|---|
| Vov | √(2Id/(µCox·W/L)) | ラザビー 2章（二乗則） |
| gm | 2Id/Vov = √(2µCox(W/L)Id) | 同 |
| ro | 1/(λId) | 同 |
| CS の利得 | −gm·(RD∥ro) | ラザビー 3章 |
| 素の利得 | gm·ro = 2/(λVov) | 同 |
| 差動利得 | −gm·RD（片側 Id） | ラザビー 4章 |
| MOS の熱雑音 | 4kTγ/gm（γ=2/3） | ラザビー 7章 |
| kTC | √(kTC)/q | 第4部 05 と同じ |
| TIA の帯域/雑音 | 1/(2πRfC)・√(4kT/Rf) | 第5部 07 と同じ |
| SC 等価抵抗 | 1/(f·C)（1クロックで q=CV を運ぶ）と √(kT/C)/サンプル | ラザビー 12章の入口 |
| 2段OTA | GBW=gm1/2πCc、PM=90°−atan(GBW/p2)−atan(GBW/z)。p2=gm2/2πCL、z=gm2/2πCc（RHP・打ち消しなし） | ラザビー 10章 |
| ADC | LSB = FS/2^N、量子化 LSB/√12、√(kT/C)、SN 比 = 20log((FS/2√2)/√(量子化²+kT/C))、ENOB = (SN比−1.76)/6.02 | 第6部 09 |
| 降圧 DC-DC | D = Vout/Vin、ΔI = (Vin−Vout)·D/(L·f)（理想・連続モード） | 第6部 10・Erickson |
| カレントミラー | 誤差 λ·ΔVDS（単純）、λ·ΔVDS/(gm·ro)（カスコード）、出力抵抗 ro・gm·ro·ro、出力に要る電圧 Vov・2Vov（低電圧カスコード） | 第6部 03・ラザビー 5章 |
| バンドギャップ | Vref = VBE + m·(kT/q)·ln n、傾き = dVBE/dT + m·(k/q)·ln n（VBE の温度係数は −2 mV/K で一定と置く） | 第6部 08・ラザビー 12章 |
| TIA の帰還容量 | Z/Rf = ωt/(Rf·CT·s² + (1 + ωt·Rf·Cf)·s + ωt)、ζ = (1 + ωt·Rf·Cf)/(2√(ωt·Rf·CT))。山は周波数を掃いて求め、鋭い山は黄金分割で詰める | 第6部 16・Graeme |

仮想プロセス: **µCox = 200 µA/V²・γ = 2/3**（0.18µm 級 nMOS の代表値）。
乱数は使わない ― 同じ設計は必ず同じ数字になり、採点も毎回同じ。

## モデルの外（正直な線引き）

- **ボディ効果・1/f 雑音・速度飽和・ミラー効果・ループの安定性（位相余裕）は入れていない。**
  Vov が 0.1V を切るあたりからは弱反転で、二乗則そのものがずれ始める（第2部の S 値の世界）。
- TIA の帯域は素の 1/(2πRfC)。実機がループゲインで帯域を伸ばす話は第6部 05。
- pMOS は nMOS の鏡像として扱わない（そもそも1個しか置かない）。
- ADC は量子化と kT/C だけ（DNL・INL・ジッタ・比較器の雑音はモデル外）。DC-DC は理想スイッチ・連続モードで、損失と出力のリップル電圧・過渡応答はモデル外。
- **第5章**: ミラーの石どうしのミスマッチ（ペルグロム則）と、カスコードの上の石の V<sub>th</sub>（ヘッドルームは低電圧カスコードの 2V<sub>ov</sub> の目安）はモデル外。バンドギャップは 1 次の傾きだけで、V<sub>BE</sub> の曲率（お椀の数 mV）とオペアンプのオフセットは入れていない。TIA の増幅器は 1 極（A = ωt/s）で、入力の電流雑音・R<sub>f</sub> の寄生容量・第 2 極は入れていない。
