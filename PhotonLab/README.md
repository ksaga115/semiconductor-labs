# 光子ラボ ― 受光チェーンを設計して、物差しで採点する

第5部『[光検出デバイス](../第5部_光検出デバイス.html)』のラボ。
**原始部品 ＝ 光子と、それを電子にする確率（η）**。
波長・パワー・量子効率・増倍率・雑音を数値で決めると、
検出器の共通の物差し ― 感度 R・SNR・NEP・D* ― がその場で出る。
課題はそれを仕様に収める設計問題（4章15問）。ブラウザだけで動く（依存ゼロ・通信ゼロ）。

```
光のパワー P ──→ 光子率 φ = P/(hν) ──→ 電流 I = R·P（R = ηλ/1240）
                                          │
        アンプ雑音 i_amp ──┐              ├─ ×M（APD: 過剰雑音 F(M) = kM+(1−k)(2−1/M)）
        暗電流ショット ────┴──→ SNR・NEP = ノイズ/R・D* = √A/NEP
```

## 画面

- **左** ― 受光チェーンの29個の数値（波長・パワー指数・η・M・k・δ・段数・暗電流・アンプ雑音・帯域・面積・容量・MPPCセル数・パルス光子数・背景光・ダークカウント・積分時間・空乏層の厚さ・受光径・TCSPC の繰り返しと寿命、第4章のクロストーク・アフターパルス・しきい値・信号の平均 p.e.・放射線のエネルギー・シンチレータの光量・集光効率・固有分解能）と、そこから出る数字。
- **真ん中** ― 2枚の図。**SNR と M**（APD の「最適な M」の山がそのまま見える）、**MPPC の入出力**（発火セル数が μ から目減りしていく飽和）。どちらも採点と同じ `photon.evaluate` から描く ― 図に嘘はない。
- **右** ― 課題。採点は設計から出た数字だけを見る（お手本と見比べない）。

## 課題 ― 4章15問

|---|---|---|---|
| | | **第1章　目盛りをあわせる** | |
| 1 | `resp` | 感度を作る | R = ηλ/1240 の逆算 |
| 2 | `rate` | ワットを個数に戻す | 1pW = 数百万光子/s |
| 3 | `nep` | 床を作る | NEP = √(2qI_d + i_amp²)/R |
| | | **第2章　増やして届かせる** | |

| 5 | `pmt` | 雪だるまを組む | δⁿ と F = δ/(δ−1) |
| 6 | `mppc` | 数えられる明るさに収める | 飽和 N(1−e^(−μ/N))、目減り 5% |
| | | **第3章　現場の制約** | |
| 7 | `fast` | 速さの敵は容量 | 1/(2πRC)、50Ω・7GHz → 0.45pF |

| 11 | `transit` | 厚さの綱引き | f_tr = 0.44v/w と f_RC = w/(2πRεA) の釣り合い |
| 12 | `pile` | TCSPC の繰り返しを選ぶ | p = 計数率/繰り返し ≤ 2%、周期 ≥ 5τ ― 窓は両側 |
| | | **第4章　増倍の雑音と数え方** | |
| 13 | `ingaas` | k = 0.4 の狭い山 | F(M) が M にほぼ比例 ― 1550 nm・100 nW で M ≈ 11〜22 の窓（頂上 M ≈ 15） |
| 14 | `thresh` | しきい値で暗計数を切る | 偽 = DCR·P_ct^(n−1) ≤ 100 cps と信号のポアソンの裾 ≥ 90% ― 5〜6 p.e. の窓 |
| 15 | `scint` | PET の分解能と飽和の窓 | 2.355√(ENF/N) と固有 8% の二乗和 ≤ 10.5%、飽和 ≤ 5% ― 約 1,260〜1,490 光電子 |

条件を固定する課題は、**固定した欄を動かすと数字が届いていても落ちる**
（アンプ雑音を勝手に下げる、光子数を勝手に減らす、の類は反則として採点される）。

## 数字はどこから来たか

| 量 | 式 | 出どころ |
|---|---|---|
| 感度 R | ηλ[nm]/1240 [A/W] | 第5部 04 |
| 光子率 φ | P/(hν)、hν = 1240/λ [eV] | 第4部の hc=1240 と同じ |
| 過剰雑音 F | kM + (1−k)(2−1/M) | McIntyre 1966 |
| PMT の F | δ/(δ−1) | PMTハンドブック |
| SNR | M·I_ph / √((2q(I_ph+I_d)F·M² + i_amp²)·B) | 教科書どおり |
| NEP | √(2qI_d·F + (i_amp/M)²)/R [W/√Hz] | 入力換算 |
| D* | √A/NEP [cm√Hz/W] | ジョーンズ |
| MPPC 飽和 | N(1−e^(−μ/N)) | セルは1発1回 |
| RC 帯域 | 1/(2π·50Ω·C) | 光通信の定番の受け |
| 背景光 | I_bg = R·P_bg がショット項と NEP に入る（BLIP: NEP → √(2qI_bg)/R） | 信号と同じ R で電流になる |
| 計数 SNR | s·√t/√(s+b)。s = φη、b = 背景光子×η + ダークカウント | ポアソン（b の平均は既知として引く） |
| 走行×RC | f_tr = 0.44·v_sat/w、C = εA/w、1/f² = Σ1/f²。ε_Si=11.7ε₀・v_sat=10⁷cm/s | Bowers の走行帯域近似 |
| パイルアップ | p = 計数率/繰り返し（p≲数% が定石）、測れる寿命 ≈ 周期/5 | TCSPC の教科書則（Becker） |
| クロストークの偽計数 | n p.e. 以上に化ける暗計数 ≈ DCR·P_ct^(n−1)（n = 2 は P_ct の定義そのもの。3 以上は連鎖を独立とみなす近似） | 暗計数の 1.5 p.e. ÷ 0.5 p.e. で P_ct を測る定義 |
| 信号の検出率 | 平均 μ p.e. のポアソンで n 個以上になる確率（クロストークの上乗せは入れない＝控えめ側） | ポアソン |
| 見かけの計数・ENF | 見かけ/本当 ≈ 1 + P_ct + P_ap、クロストークの過剰雑音 ENF ≈ 1 + P_ct（どちらも小さい確率での一次近似） | 分岐の模型（幾何・Borel）はどちらも一次で 1 + P_ct |
| エネルギー分解能 | FWHM = √((2.355·√(ENF/N))² + 固有²)、N = E·光量·集光·PDE | 第5部 05（2,000 光電子で 5.3%）、Knoll |
| シンチの飽和 | 1 − N_cell(1 − e^(−N/N_cell))/N（主の光電子だけ。クロストークが使うセルは数えない） | 第2章の MPPC 飽和と同じ式 |

乱数は使わない ― 同じ設計は必ず同じ数字になり、採点も毎回同じ。

## モデルの外（正直な線引き）

- **1/f 雑音・APD暗電流の非増倍成分は入れていない。** NEP がデータシートよりきれいに出るのはそのぶん。
- MPPC のクロストークとアフターパルスは第4章で**一次近似だけ**入れた（見かけの計数 1 + P_ct + P_ap、ENF 1 + P_ct、
  偽計数 DCR·P_ct^(n−1)）。確率は入力する数で、オーバー電圧 V_ov・温度への依存（どちらも V_ov で上がる、第5部 03）は入れていない。
  課題の 500 kcps・P_ct 0.10・固有分解能 8% は仮定の値（素子と結晶のデータシートで置き換える）。
- 計数モードは不感時間なしの理想カウンタ（背景は「平均既知として引く」― 測り直すなら雑音は √(s+2b)）。
  TCSPC のパイルアップは確率 p = 計数率/繰り返し の**判定だけ**で、歪んだ減衰カーブそのものは計算しない。
- PMT の δⁿ は換算表示で、SNR の本流（M と F(M)）とは独立の枠。
- 走行時間の帯域は `transit` の欄（空乏層の厚さ・受光径）でだけ入る。`fast` の RC 帯域は容量の欄だけで決まり、走行は掛けていない。
